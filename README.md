## Самостоятельная работа: функции, триггер в Yandex Cloud

#### Файлы:

- `main.py` — функция обработки события
- `deploy_function.sh` — деплой функции в ЯО
- `trigger.sh` — создание триггера на bucket

### Как развернуть

Потребуется Yandex Cloud CLI (yc)

### 1. Задеплоить функцию

```bash
bash deploy_function.sh
```

### 2. Создать триггер

```bash
bash trigger.sh
```

### 3. Загрузить файл, чтобы вызвать триггер

```bash
➜ yc storage s3api put-object \
  --body ./test.txt \
  --bucket itmo-trigger-bucket \
  --key input/test.txt
```

После загрузки функция автоматически сработает (можно увидеть в логах yc).

### Результат:

- Функция записывает событие в файл `/tmp`
- Выводит его содержимое в лог
- Возвращает JSON-ответ

#### Примечание:

При вызове функции напрямую (через браузер или curl) IP-адрес клиента может быть записан во временный файл /tmp и попадёт в лог (IP попадает в лог автоматически, потому что вся структура запроса сохраняется целиком, это поведение Yandex Cloud). Для учебных целей это допустимо, но при использовании в проде следует очищать или маскировать.
